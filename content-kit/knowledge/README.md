# دانش سایت

## کجا چه بگذارم؟ (Agent خودکار از همه اینها می‌خواند؛ نیازی به معرفی نیست)

| می‌خواهم… | بگذارم کجا | بعدش |
|---|---|---|
| قانون، بخشنامه، شرایط مجوز | `rules/نام.md` (هر قانون یک فایل؛ بالا `trades:` / `services:` / `regions:` را بنویسید تا فقط برای همان‌ها به کار رود) | `npm run kit` |
| آدرس و ساعت اداره، اتحادیه، اتاق اصناف | `places.csv` (`verified` = yes) | `npm run kit` |
| موضوع و کلمهٔ کلیدی برای نوشتن | `keywords.csv` | `npm run kit` |
| حقیقت‌های تأییدشدهٔ هر رسته (مثلاً آرایشگاه زنانه) | `src/data/trades.json` ← `notes` | `npm run kit` |
| مدارک و مراحل هر خدمت | `src/data/services.json` و `public/flows/*.json` | `npm run kit` |
| ظاهر/لحن یک نوع نوشته | `content-kit/styles/*.md` | `npm run kit` |
| یک نمونهٔ خوب برای تقلید | `content-kit/examples/*.md` | `npm run kit` |

با `npm run dev` یا `npm run agent` کیت خودکار ساخته می‌شود؛ جداگانه چیزی را فراخوانی نکنید. فایل بدون سرصفحه هم قبول است (عنوان از نام فایل گرفته می‌شود)، ولی منبع را داخل متن بنویسید.

هر چه اینجا بگذارید، Studio و Engine برای غنی‌کردن مقاله‌ها از آن استفاده می‌کنند. **فقط چیزی بنویسید که از صحتش مطمئن هستید و منبعش را دارید.**

- `keywords.csv` — کلمات کلیدی: عبارت، خدمت، منطقه، نیت جستجو (informational/local/commercial)، اولویت.
- `places.csv` — مکان‌های مرتبط (اداره، اتحادیه، اتاق اصناف…): منطقه، نوع، نام، آدرس، ساعت، منبع و ستون `verified` (yes/no). فقط ردیف‌های `yes` در مقاله‌ها استفاده می‌شوند.
- `rules/*.md` — هر قانون یا بخشنامه یک فایل. بالای فایل:
  ```
  ---
  id: R-001
  title: عنوان قانون یا بخشنامه
  source: لینک یا نام سند
  date: 2026-01-01
  services: [business-license]
  regions: []
  ---
  متن خلاصه یا نقل‌شده با ذکر دقیق.
  ```
- مدارک و مراحل هر خدمت از `public/flows/*.json` و `src/data/services.json` خودکار خوانده می‌شود.

بعد از هر تغییر `npm run kit` (یا هر `npm run dev` / `npm run build`) بسته را دوباره می‌سازد.
